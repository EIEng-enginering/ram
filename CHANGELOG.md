## 20 November 2026 · 0.3.0.dev1 development checkpoint (method rammodel-des-0.3)

All times AWST (UTC+8). Built and tested on Linux only; Windows acceptance pending.

**Baseline (WP0).** Manifest verified 66/66. Untouched 0.2 suite 20/20 on Python 3.12.16. Offshore reference at
1,000 replications, seed 42, reproduced exactly (99.264246 %, +0.676380 pp, +0.539137 pp, −0.540236 pp).

**Schema 3 (migration 003_provenance.sql).** Adds `mode_value_meta` (value basis stated/inferred/estimated/synthetic,
applicability, import batch), `import_batch`, `model_revision` (backfilled from the 0.2 study row) and
`failure_observation`. The 0.2 `mode_value` table is unchanged so 0.2 positional inserts and exchange files still work.
Rows that came from the shipped examples are backfilled as `synthetic`.

**New modules.** units.py, mapping.py, observations.py, editing.py, decision.py, intake.py.

**Method version rammodel-des-0.3.** New physics and events are active only when a model uses a 0.3 feature
(listed as `method_profile` in every run record and report). Models without 0.3 features follow the 0.2 event order and
RNG streams exactly; 240 fixed replays generated by the untouched 0.2 source are reproduced bit-for-bit
(tests/fixtures/alpha_0_2_reference_replays.json). New events are queued after legacy events, and new random draws use
separate streams ("repair", "demand", "@ccf"). Details: docs/METHODS_IMPLEMENTED.md.

**Defect found and fixed during development (CTMC verification).** The first 0.3 standby implementation kept aging an
idle standby unit (idle_factor > 0) while that unit was itself failed. The independent CTMC check exposed it: s = 0.3,
idle = 0.5 gave 0.8768 simulated against 0.8835 expected. Fixed so a unit only accrues idle age while available and not
operating (no aging while failed, under maintenance or under test). That case is now in the test suite and in
tools/verify_references.py, and the start-up bias allowance was tightened to 0.0015.

**Changes to existing tests (none deleted, none weakened).**
- test_storage: hard-coded schema version literals (2 and 3) replaced by `storage.SCHEMA_VERSION` and
  `SCHEMA_VERSION + 1`. Intent unchanged: current schema is opened, newer schema is rejected.
- test_workflow: final export now also requires a named run approval (WP5 separate model/run/narrative approvals). An
  assertion was added that final export fails without it, then the approval is given and the original assertions run.

**Development failures and how they were resolved (historical record).**
1. Adding columns directly to `mode_value` broke the 12-column positional inserts used by 0.2 code and exchange files.
   Resolved by moving the new attributes to the side table `mode_value_meta`.
2. A first 2oo3 flow test expected 0.972 for three 50 %-capacity trains. That expectation was wrong: a capacity
   arrangement gives 0.9855 by hand. Kept as a capacity test (0.9855) and a separate voting test (0.972) added.
3. Priority routing left flows at 99.9999999 because of LP slack tolerance. Stage tolerance reduced to 1e-12 relative.
4. A yield-only model took the legacy path and produced no balance. Feature detection now includes edge and mode keys.
5. Stale (superseded) failure events appeared in event traces. A staleness check now skips them before recording.
6. The idle-aging defect above.
7. WP4: with matched streams a tiny real change is statistically significant, so the "insignificant difference" control
   now uses an unmatched (renamed) stream with identical parameters. The ranking-change test uses U[50, 500], for which
   P(option X best) = 1/3 by hand; 0.375 was observed with the test's sample size.
8. Report agreement tool: PDF table cells wrap long numbers, so PDF metric checks match "<metric><unit><mean>" with line
   breaks removed. A tampered report copy is rejected (negative control in TEST_RESULTS/REPORT_AGREEMENT.txt).

**Examples.** Offshore example regenerated with 0.3 code (numbers identical; schema 3 case). Alpha case copy migrated.
New synthetic onshore gas plant example and an independent utility reference case with a hand calculation.

**AI.** PROMPT_VERSION evidence-tools-2: provider errors are wrapped without headers or credentials; provider output must
be a JSON object with the checked schema; actions may state basis stated/inferred and inferred actions are tagged
"AI INFERENCE". Local document intake added (text, text-layer PDF). AI remains off by default.
